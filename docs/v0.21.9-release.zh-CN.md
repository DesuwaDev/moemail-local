# MoeMail Local v0.21.9

本版本新增逐设备会话管理和 IP 地区显示，完善 CDN 来源 IP 配置，并修复网络异常时账户权限界面的兜底行为。

## 更新内容

- 用户可查看已登录设备，单独退出任意会话，或退出其他/全部会话；皇帝可在用户详情中管理指定用户的会话。
- 会话显示 UA、首次登录时间、最近访问时间、首次/最近 IP 和估算累计活跃时长，采用分页与紧凑详情，适配手机横竖屏和桌面。
- IP 地区由服务器查询，按 GeoJS → ipwho.is → country.is 回退，显示可用的国家、省州、城市及网络信息；查询有缓存、超时、并发和地址过滤，不阻塞登录或退出。
- 运行配置新增“来源 IP / CDN”，支持常见 CDN、自定义请求头和代理链位置；皇帝可检测当前请求，对比生效配置与草稿结果，检测不会自动保存或启用信任。
- 来源 IP 解析同时用于会话记录与登录限流，兼容 IPv6、带端口的地址、Forwarded 和 Cloudflare Pseudo IPv4；新增 Cloudflare Caddy/Nginx 示例及通用 CDN 接入说明。
- 修复网络异常、会话或权限尚未加载时混用旧角色的问题；权限未确认前不显示管理面板，加载失败提供重试。
- 修复运行配置在 320px 窄屏下被长配置键名撑宽的问题，并同步五种界面语言。

## 升级说明

- SQLite/PostgreSQL 启动时自动执行 `0009_login_sessions`。已有有效登录在首次访问时补录，不能追溯此前的登录时间、IP/UA 和活跃时长，界面会明确标注。
- 旧配置自动补齐 `server.clientIpHeader: auto` 和 `server.clientIpTrustedHops: 1`，旧备份配置仍可读取。未开启 `server.trustProxyHeaders` 时不采用来源头。
- 默认代理链从最右侧取 1 个 IP。仓库原有单值覆盖配置不受影响；自定义多级追加链部署需按实际链调整取值位置。
- 启用来源头信任前，入口必须覆盖所选头并限制源站直连。应用内检测不能验证 TCP 对端；无法还原访客 VPN/代理背后的原始地址。
- 地区查询会向所用服务发送待查询的公网 IP，不发送账户、Cookie、UA 或邮件。IP 地理位置是估算值，并非真实住址。
- 升级前备份数据库和配置。详细行为、隐私与反代配置见 [登录会话与 CDN 接入说明](login-sessions.zh-CN.md)。
