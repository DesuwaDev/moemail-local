# MoeMail Local v0.21.11

邮件外部资源提示栏新增“资源详情（数量）”，通过紧凑弹窗查看资源类型、来源域名、路径、重复引用次数及当前限制状态，无需展开折叠栏或拉长正文。

- 图片与背景、媒体、字体、外部样式等分类展示，重复引用合并；每页 6 项，弹窗内部滚动，适配手机横竖屏和桌面。
- 资源识别在不执行内容的模板内完成，不主动访问地址；列表不提供外链，隐藏 URL 凭据、查询参数和片段，限制路径长度与展示数量。
- 详情来自正文静态识别，并非实际网络日志；候选资源可能未被使用，特殊写法可能遗漏。内嵌图片与普通链接不计入，脚本和嵌入页面继续由原有清理逻辑移除。
- 允许加载后同步显示允许与仍受限制的资源类型，保留原有邮件沙箱、CSP 和防追踪行为，支持五种界面语言。

## 验证

生产构建、TypeScript、修改文件 ESLint 和五语言检查通过。浏览器验证资源分类、重复引用、CSS 转义、参数隐藏、数量上限、分页与允许加载状态，并检查 320/390px 窄屏、844px 横屏及 1440px 桌面布局。

本补丁不新增数据库迁移、配置项或依赖。Docker 发布沿用四类镜像的 amd64/arm64 构建、运行检查和版本/latest 标签流程。
