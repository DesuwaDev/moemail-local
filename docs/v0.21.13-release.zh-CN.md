# MoeMail Local v0.21.13

邮件外部资源拦截支持选择性加载：可在「资源详情」中勾选信任的资源单独放行，其余继续拦截。

- 拦截状态下，图片 / 背景、音视频 / 字幕、字体条目可勾选，并提供全选、取消全选、加载所选与恢复拦截操作。
- 放行仍由沙箱 CSP 执行：仅将所选资源按协议、主机与完整路径逐条加入对应的 `img-src`、`media-src`、`font-src`，未选资源保持仅允许 `data:`。
- 外部样式与其他引用仍始终拦截，不可勾选；已选择「加载资源」或账户开启自动加载时不显示勾选。
- 顶栏显示已加载所选项数量；「阻止本封」会清空选择并恢复完全拦截。选择仅对当前邮件与当前账户生效，不持久化。
- 资源详情改为按「来源 + 完整路径」去重，查询参数不同的同一路径合并计数（CSP 本身不区分查询参数）；以 `/` 结尾的路径按 CSP 目录前缀匹配，列表中的放行状态与浏览器实际行为一致。
- 路径中的特殊字符会百分号编码后写入策略，不会拆分策略或被解析为 HTML 字符引用。

修改文件 ESLint、TypeScript 与 i18n 校验通过，并以无头 Chrome 验证仅请求所选资源、特殊字符路径匹配及目录前缀行为。发布流水线执行既有检查和四类 Docker 镜像的 amd64/arm64 构建、运行检查与标签发布。

本版本不新增数据库迁移、配置项或依赖。
