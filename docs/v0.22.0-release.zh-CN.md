# MoeMail Local v0.22.0

新增通行密钥（Passkey）登录与管理：用指纹、面容或设备 PIN 免密登录，通行密钥与站点域名绑定，可防钓鱼。详见[通行密钥说明](passkeys.zh-CN.md)。

- 登录页新增「使用通行密钥登录」，无需输入用户名、密码或人机验证。
- 个人中心「登录安全」分为「通行密钥」与「设备与会话」两行；通行密钥可添加、重命名、删除，列表显示保存位置、同步状态及添加和最近使用时间，每个账户最多 10 个。
- 添加或删除前，当前会话须在 10 分钟内登录或完成验证，可用已有通行密钥或当前密码验证；重命名无需验证。
- 皇帝可在「用户 → 用户详情 → 登录」（原「会话」标签）查看并删除指定用户的通行密钥；添加与删除写入管理日志。
- 用通行密钥登录的会话在「设备与会话」中显示登录方式为「通行密钥」；设备上残留已删除的通行密钥时，登录会明确提示，支持的浏览器会尝试隐藏该副本。
- 强制用户验证与可发现凭据，不收集设备证明；一次性服务端挑战（5 分钟，绑定用户与会话）、严格校验 origin 与 RP ID、签名计数器回退拒绝；管理接口仅限浏览器会话，登录挑战与密码验证计入登录频率限制。

部署要求：`server.baseUrl` 须为 HTTPS 域名（本地开发可用 `http://localhost`），并通过该地址访问；HTTP 域名或 IP 地址部署时不显示通行密钥入口，管理面板会说明原因。验证在服务器本地完成，不依赖外部服务。

SQLite / PostgreSQL 自动迁移 `0010_passkeys`：新增 `passkey`、`passkey_challenge` 表及 `login_session.verified_at` 列；维护清理任务同时清除过期挑战。新增依赖 `@simplewebauthn/server` 14.0.3 与 `@simplewebauthn/browser` 14.0.0。

新增 `pnpm validate:passkeys`，以软件认证器覆盖注册、登录、再次验证、删除、上限、级联删除及重放、跨会话挑战、错误来源、缺少用户验证、签名篡改、计数器回退和他人凭据等拒绝路径，已在 SQLite 与 PostgreSQL 上通过并加入发布检查。发布流水线执行既有检查和四类 Docker 镜像的 amd64/arm64 构建、运行检查与标签发布。
