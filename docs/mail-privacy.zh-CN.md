# 邮件预览防追踪

HTML 邮件默认禁止自动加载外部图片、背景图、字体和音视频，包括隐藏的追踪像素。邮件自身的 CID 图片和内嵌数据仍可显示，附件下载及普通链接保留。

正文上方的紧凑状态栏显示「外部资源已阻止」和「加载资源」。点击后仅允许当前预览加载；「阻止本封」可阻止后续加载，但不能撤回已经发送的请求。切换邮件、重新打开预览或从纯文本切回 HTML 时，重新使用账户的默认设置。

账户 → 邮件隐私可开启「始终允许加载外部资源」。默认关闭；每次开启都需要确认风险，开启后设置下方与每封 HTML 邮件均保留小提示。该偏好保存在账号中，登录会话刷新后同步到其他设备，也可以随时关闭。开启后仍可单独阻止当前邮件；改变屏幕尺寸不会丢失该选择。分享页使用访问者自己的偏好，匿名访问仍默认拦截，不继承分享者的许可。

允许加载后由浏览器直接请求外部资源，发件人仍可能得知出口 IP 与阅读情况；主动打开邮件里的链接也不在自动加载拦截范围内。

## 实现与升级

使用 inert template 解析 HTML，避免清洗阶段提前发出图片请求；沙箱内的 CSP 在任何邮件内容之前生效，默认仅允许 data 资源。允许外部资源时仍保持脚本、嵌套页面、表单和外部样式表禁用，并移除链接 ping 和归因属性。桌面与手机共用一份预览，避免隐藏副本请求外部资源。

账户偏好接口仅允许当前登录用户修改自己，验证请求来源及严格的布尔参数，不接受 API Key。会话每次从数据库读取该偏好，不信任客户端提交的 JWT 数据；封禁账号不会自动加载。SQLite 与 PostgreSQL 均新增 0007_mail_privacy 迁移，现有账号默认关闭，旧数据库导入缺少该字段时也默认关闭。沿用既有会话查询，不额外增加每封邮件的数据库查询。

账户页缩小头像、卡片留白及间距；常用额度在手机分两列、桌面分四列显示。完整规则和解释默认折叠，展开后保留全部原有内容。

## 验证记录

使用隔离数据库、真实生产构建和本机 HTTP 追踪端点验证默认拦截、主动加载及账户偏好：匿名访问已开启许可的分享者邮件仍为 0 请求；登录后两封邮件分别请求 9 种测试资源，各一次。单封阻止、切换屏幕尺寸和关闭账户选项均不增加请求，跨标签同步恢复拦截。所有请求不带 Referer，脚本、iframe、刷新跳转及外部样式表不会加载。SQLite 与 PostgreSQL 验证迁移默认值、跨会话持久化、用户隔离、未登录/跨源/API Key 拒绝和参数校验。

界面沿用现有主题、按钮及边框，在 320/390 像素手机竖屏、844×390 横屏和 1440×900 桌面检查换行与滚动。分享页使用动态视口高度并保留最小阅读区，短屏可滚动查看。
