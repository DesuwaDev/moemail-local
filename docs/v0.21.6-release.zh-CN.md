# MoeMail Local v0.21.6

本版本新增邮件外部资源防追踪与账户隐私偏好，并压缩账户页面的空间占用。

## 更新内容

- HTML 邮件默认阻止外部图片、追踪像素、背景图、字体及媒体；CID 内嵌图片、附件与普通链接继续可用。
- 账户 → 邮件隐私新增「始终允许加载外部资源」，默认关闭。每次开启需要确认风险，设置页和邮件正文上方保留紧凑提示，并可单独「阻止本封」。偏好跟随账号保存，其他登录会话刷新后同步；分享页使用访问者自身设置，匿名访问保持默认拦截。
- 外部资源放行后由浏览器直接加载，发件人仍可能获知出口 IP 和阅读情况。脚本、嵌套页面、表单和外部样式表继续禁用，请求不发送 Referer。
- 桌面与手机共用单份邮件预览，消除隐藏副本的重复资源请求；旋转屏幕或改变窗口尺寸不会丢失当前邮件的阻止选择。
- 账户页缩小头像、卡片留白和间距，常用额度分列展示，完整规则及解释可按需展开；调整短屏邮件阅读区与分享页动态高度。
- 账户偏好接口限制为本人登录会话，包含跨源请求、参数与用户隔离检查；兼容五种界面语言。

## 升级说明

SQLite 与 PostgreSQL 均新增 `0007_mail_privacy` 迁移，由现有启动迁移流程执行。现有账号和缺少该字段的旧数据库导入均默认关闭自动加载。升级前按既有流程备份数据库与配置。

邮件里的外部图片可能需要手动点击「加载资源」，或在账户设置确认后开启自动加载。「阻止本封」不能撤回已经发送的请求；重新打开邮件时恢复账户默认设置。

## 验证

- 生产构建、TypeScript、Lint、五语言与布局检查通过。
- SQLite/PostgreSQL 实际 HTTP 验证迁移默认值、跨会话持久化、用户隔离、未登录/跨源/API Key 拒绝和严格参数校验。
- 真实浏览器验证默认零外部请求、允许后每种资源仅加载一次、单封阻止及跨标签同步；禁止资源未发出请求。
- 检查 320/390 像素手机竖屏、844×390 横屏和桌面布局。
- 发布流水线验证四类镜像的 Linux amd64/arm64 原生构建与运行。
