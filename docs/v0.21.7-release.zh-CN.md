# MoeMail Local v0.21.7

本版本重新整理账户额度区，让实际规则和用量直接可见，减少重复卡片、说明及留白。

## 更新内容

- 移除「查看完整规则摘要」折叠，直接展示收发额度、适用范围、共享方式、统计周期、已用/上限、处理中数量及邮箱生命周期额度。
- 资源限制改为标签和值对齐的紧凑列表，宽屏分两列；收发额度在宽屏并排，手机按顺序展示，长邮箱地址自动换行。
- 重复解释集中到可点击的「额度说明」，保留原有说明内容，实际规则和数字始终显示。
- 登录安全按钮与标题同排，简化重复描述，保留退出所有设备的确认及 API Key 提示。
- 同步五种界面语言和邮件隐私文档。

## 升级说明

从 v0.21.6 升级无需新增数据库迁移。本次仅调整展示，不改变额度计算、权限判断或邮件隐私偏好。

## 验证

- 生产构建、TypeScript、Lint、五语言与现有布局检查通过。
- 真实浏览器检查 320/390 像素手机、844×390 横屏和 1440×900 桌面。
- 验证共享与个人规则、长邮箱地址、处理中预留、生命周期额度及触屏说明入口的完整显示。
- 发布流水线验证四类镜像的 Linux amd64/arm64 原生构建与运行。
