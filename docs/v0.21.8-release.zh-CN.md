# MoeMail Local v0.21.8

本版本完善皇帝的用户、邮箱与权限管理，修复单邮箱收发统计，并保持后台在手机和桌面上的紧凑布局。

## 更新内容

- 支持按邮箱名或完整地址查找邮箱及所属用户，用户搜索同时匹配名下邮箱。
- 用户详情可查看收件箱、发件箱、邮件正文和附件，搜索邮件并删除单封邮件或整个邮箱。
- 邮箱支持停用与恢复、独立控制收信/发信/分享、修改有效期和永久有效；限制同时覆盖普通用户、API Key、分享链接及 Mailu 收发路径。
- 保留现有四种角色，提供角色默认值与单用户覆盖，细化正文、附件、删除邮件权限，以及常规配额和域名规则。
- 支持撤销普通用户会话、停用现有 API Key/Webhook、撤销全部分享；邮箱管理、正文/附件访问和资源撤销写入操作记录。
- 修复单邮箱统计子查询错误关联导致的零计数，保留删除前的历史配额用量；修复旧版用户权限校验器拒绝新增权限的问题。
- 用户详情采用分栏与有界滚动，邮箱每页 8 条、邮件每页 10 条、权限每页 6 项；配额说明移至对应页签，减少无关内容占用。
- 修复后台邮件预览正文高度和永久邮箱的时区显示问题，同步五种界面语言，保留隔离渲染和外部资源防追踪。

## 升级说明

- SQLite/PostgreSQL 启动时自动执行 `0008_mailbox_management` 迁移。旧邮箱默认保持启用，允许收发和分享。
- 权限配置升级为版本 8，新增能力继承原有查看、删除权限，保留用户覆盖规则。
- 升级前备份数据库和配置；如需回退旧版，应同时恢复升级前的数据库与配置备份。
- 新增跨用户管理接口仅接受皇帝登录会话，不接受 API Key；不会显示密码哈希或密钥明文。
