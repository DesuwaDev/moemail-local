# MoeMail Local v0.22.2

运行配置按任务重新分组，并在不折叠、不分页的前提下压缩页面长度。YAML 文件结构不变。

## 分组

- 由 10 个与 YAML 顶层键一一对应的分组，改为 7 个按任务划分的分组：站点与网络、登录方式、安全、数据库、备份与同步、数据清理、监控告警。
- 备份间隔、各驱动的备份目录与保留天数、异地同步集中到「备份与同步」；清理间隔归入「数据清理」；切换驱动时自动退出归入「数据库」；Worker 投递密钥与皇帝引导密钥归入「安全 → 接口密钥」；GitHub、Google、通行密钥归入「登录方式」。
- 配置格式与初始化时间改为页头只读信息，如需修改使用原始 YAML。
- 新增校验：每个配置项必须恰好出现在一个分组或只读信息中。

## 长度

- 手机上纯数字设置两两并排，其余控件整行；桌面按小节字段数使用一至三列。
- YAML 键名跟随说明显示（手机隐藏，标签悬停可见），不再单独占行。
- 手机上分组选择与搜索合并为一行并吸顶，面板说明与分组标题仅在宽屏显示；桌面侧栏列出当前分组的小节，可直接跳转。
- 实测最长分组页面高度：手机 2975 → 2010 px，桌面 1913 → 1387 px。

部署文档与通行密钥文档的界面路径已同步更新。TypeScript、ESLint、全部发布前校验、生产构建通过；以无头 Chrome 验证桌面 / 平板 / 手机竖横屏布局、数字并排、搜索、未保存计数、问题跳转与小节跳转，并回归通行密钥完整流程。

本版本不新增数据库迁移、配置项或依赖。
