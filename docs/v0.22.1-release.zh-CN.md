# MoeMail Local v0.22.1

新增通行密钥开关，重做运行配置布局，并修复弹窗与下拉框的多余选中描边。

## 通行密钥开关

- 运行配置 → 登录与鉴权 →「启用通行密钥」（`auth.passkeys.enabled`，默认开启），保存后热加载。
- 关闭后登录页隐藏通行密钥入口，签发、登录、添加和通行密钥再次验证一律返回 `PASSKEY_DISABLED`，关闭前已发出的登录挑战同样失效。
- 已添加的通行密钥保留：无通行密钥的用户不显示该入口，已有的用户看到「已暂停」说明，仍可查看、重命名和删除；再次验证改用密码或重新登录。已登录会话不受影响，重新开启后立即恢复。
- 旧配置文件与备份缺少该字段时按开启处理，维护与数据库工具镜像的配置读取保持兼容。

## 运行配置布局

- 取消分组折叠栏：宽屏左侧分组导航、右侧单组内容，窄屏改为下拉选择分组。
- 组内按子对象分节（如 GitHub 登录、Google 登录、通行密钥、登录与注册限流、SQLite / PostgreSQL），未使用的数据库驱动小节有标注；字段统一为标签在上、控件在下的两列网格。
- 新增跨分组搜索（名称、说明、YAML 键名）；导航显示未保存修改与待处理问题标记，校验问题可点击跳转到对应字段。
- 保存栏吸底并显示未保存修改数量，手机上压缩为单行，并避开右下角悬浮按钮。

## 界面修复

- 弹窗打开时关闭按钮不再默认显示选中底色与描边；下拉框选择后不再残留描边。两者仅在键盘操作时显示焦点环。

TypeScript、ESLint 与全部发布前校验通过；`validate:passkeys` 在 SQLite 与 PostgreSQL 上覆盖开关场景，部署约定校验新增旧配置兼容与非法值用例。以无头 Chrome 验证开关各状态、运行配置桌面 / 平板 / 手机竖横屏布局、搜索、未保存计数与问题跳转，以及弹窗与下拉框的鼠标 / 键盘焦点表现。

本版本不新增数据库迁移或依赖。
